### 🚀 Proyectos destacados

**🔬 Detección y Conteo Automático de Bacilos de Tuberculosis (Tesis EPIS-UNSCH)**
* **Descripción:** Proyecto de investigación basado en el análisis de imágenes microscópicas de esputo teñidas con Ziehl-Neelsen utilizando algoritmos de visión computacional.
* **Aspectos clave:** Implementación del modelo YOLOv10 y Redes Neuronales Convolucionales (CNNs). Integración de Inteligencia Artificial Explicable (Grad-CAM XAI) para dotar de transparencia a las predicciones médicas y evaluación mediante la escala SUS.

**🩺 Analizador Visual Médico con IA**
* **Descripción:** Aplicación web para el análisis de imágenes diagnósticas multi-vista (Rayos X, resonancias magnéticas, tomografías).
* **Aspectos clave:** Desarrollo frontend con React y TypeScript integrando componentes drag-and-drop. Backend serverless construido con Express.js y Node.js que orquesta el análisis de las imágenes médicas a través de la API de Google Gemini.

**🏫 Plataforma de Aula Virtual Offline (I.E.P. Nuestra Señora de las Mercedes)**
* **Descripción:** Sistema educativo diseñado para funcionar en una intranet local sin requerir conexión a internet, pensado para tablets y dispositivos móviles en escuelas.
* **Aspectos clave:** Aplicación de la metodología Spec-Driven Development (SDD) para la planificación técnica. Permite a los docentes gestionar material académico de forma descentralizada. Acompañado de un servicio social universitario para orientar vocacionalmente a los alumnos.

**🏢 Identidad Corporativa y Desarrollo Web para FADIINSER S.A.C.**
* **Descripción:** Diseño integral de marca y presencia digital para una firma de ingeniería industrial.
* **Aspectos clave:** Creación de logos metálicos 3D y paleta de colores. Desarrollo de sitio web responsivo desplegado mediante GitHub Pages con dominio personalizado, configuración de indexación SEO, sitemap.xml e integración de correos corporativos en Zoho Mail.

**🚧 Prototipo IoT: Barrera de Tráfico y Control de Acceso Automático**
* **Descripción:** Sistema de hardware automatizado para el control de ingreso.
* **Aspectos clave:** Construido sobre Arduino UNO utilizando sensores infrarrojos FC-51, servomotores y pantallas LCD, aplicando conocimientos de análisis de circuitos y programación C++.
